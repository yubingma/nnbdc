# 📄 炭炭背单词 PDF 文字提取修复指南

#### 1. 问题背景
从“炭炭背单词”等 App 导出的 PDF 文件，为了保护版权和防止数据抓取，通常会对 PDF 的**文本层**进行特殊处理。虽然视觉上单词显示正常，但直接复制或使用常规工具提取时，会出现大量的拼写变形（如 `butterfly` 变成 `butte‘ly`）。

#### 2. 技术原理：自定义字符映射 (Custom Encoding)
该软件在生成 PDF 时，利用了 PDF 字体子集化技术，将常见的字母组合（合字）映射到了非标准的字符编码（Extended ASCII/Control Characters）。由于这些映射在单个 PDF 文件内是全局一致的，因此可以通过逆向映射表进行还原。

#### 3. 核心修复映射表
经过对 2026 大纲词汇 PDF 的深度扫描与交叉验证，以下是“炭炭背单词”目前使用的核心混淆映射表：

| 原始编码 (Hex) | 符号预览 | 对应正确拼写 | 常见示例 |
| :--- | :--- | :--- | :--- |
| `0x87` | `‡` | **ff** | `a‡air` -> `affair` |
| `0x8a` | `Š` | **ffi** | `aŠliate` -> `affiliate` |
| `0x8c` | `Œ` | **ffl** | `aŒuent` -> `affluent` |
| `0x8e` | `Ž` | **fi** | `Žction` -> `fiction` |
| `0x90` | `‘` | **fl** | `con ict` -> `conflict` |
| `0x91` | `’` | **rf** | `dwa’` -> `dwarf` |
| `0x92` | `”` | **rt** | `a”` -> `art` |
| `0x93` | `“` | **rv** | `inte“al` -> `interval` |
| `0x94` | `•` | **rx** | `Ma•ist` -> `Marxist` |
| `0x95` | `–` | **ry** | `ang–` -> `angry` |

#### 4. 如何使用修复脚本
在该目录下，你可以直接运行 `tantan_pdf_extractor.py` 来处理 PDF 文件。

**目录结构建议：**
```text
tools/book/
  ├── 炭炭/
  │   ├── tantan_pdf_extraction_guide.md  (本说明)
  │   └── tantan_pdf_extractor.py         (提取脚本)
  └── 考研/
      └── [你的PDF文件].pdf
```

**脚本功能：**
1.  自动识别 PDF 中的序号列和单词列。
2.  应用上述映射表修复所有变形单词。
3.  自动去重并按原顺序输出 `0|单词` 格式。

#### 5. 结论
这种破解方式在处理该 App 导出的文件时非常高效且准确。只要 PDF 内部的字体映射逻辑未发生重大变更，上述映射表可以长期沿用。
