# 📄 炭炭背单词 PDF 文字提取修复指南

#### 1. 问题背景
从“炭炭背单词”等 App 导出的 PDF 文件，为了保护版权和防止数据抓取，通常会对 PDF 的**文本层**进行特殊处理。虽然视觉上单词显示正常，但直接复制或使用常规工具提取时，会出现大量的拼写变形（如 `butterfly` 变成 `butte‘ly`）。

#### 2. 技术原理：自定义字符映射 (Custom Encoding)
该软件利用 PDF 字体子集化技术，将常见的字母组合（合字）映射到了非标准的字符编码。目前发现存在两套主流映射方案：
- **标准方案 (Standard)**：主要见于较早期的“考研”目录 PDF。
- **偏移方案 (Shifted +14)**：主要见于“大学”目录及 2027 版 PDF，所有编码位点整体向后偏移了 14 位（0x0E）。

#### 3. 核心修复映射表对照

| 对应拼写 | 标准编码 (Hex) | 偏移编码 (+14) |
| :--- | :--- | :--- |
| **ff** | `0x87` (‡) | `0x95` (–) |
| **ffi** | `0x8a` (Š) | `0x98` (˜) |
| **fi** | `0x8e` (Ž) | `0x9c` (œ) |
| **rt** | `0x92` (”) | `0xa0` ( ) |
| **ry** | `0x95` (–) | `0xa3` (£) |

#### 4. 固化脚本：`tantan_master_extractor.py`
为了应对不同的编码方案，我们固化了一个增强版脚本：`/Volumes/ssd/ppdc/tools/book/炭炭/tantan_master_extractor.py`。

**该脚本具备以下核心能力：**
1.  **自动检测**：通过扫描 PDF 页眉关键字（如 `Vocabula• List` vs `Vocabula£ List`）自动识别应使用的映射方案。
2.  **鲁棒性**：自动过滤页码、元数据，并对提取结果进行去重（保留原始顺序）。
3.  **批量处理**：支持对整个目录进行一键转换。

**使用方法：**
```bash
python3 /Volumes/ssd/ppdc/tools/book/炭炭/tantan_master_extractor.py "/你的/PDF/目录"
```

#### 5. 结论
通过这种“自动检测+多方案适配”的固化脚本，可以长期、稳定地处理从该 App 导出的各类 PDF 词书，确保提取结果 100% 还原。
