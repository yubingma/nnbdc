这一版换掉了什么

1. 中心的日历签到印章（细描边日历/对勾 + 已打卡 + 日期）→ 换成「今日词画报」：以今天第一个有核心意象的词的意象图为主角，多个释义从核心意象生长出去。
2. 3.5px 细胶囊进度条 → 换成记忆守护兽趴在「水位线」上：它就是进度本身，前面是走过的水量，身后是今天还没走的。
3. 公共风景壁纸 → 换成极简深空底 + 极缓星点，把视觉焦点让给意象图。
4. 通用的「TODAY'S PLAN / 今日学习计划」标题 → 换成只属于这个用户的「第 137 个背词日」（背词日序数，永不归零）。
5. 打卡成功 → 在画报上盖一枚「今日之印」，当天学的那个意象就成了这一天的印记。

落地时的真实数据约束

生产库 word_core_image 现有 41681 条核心意象记录，其中已生成图片的 8706 条（全库 79474 词的约 11%），有核心意象文字但还没出图的 32975 条。
所以画报是两档一等公民：有图档出意象图；排版档把核心意象短语（如「同模成形」）用大字号排版驱动呈现，配同样的释义生长结构，不依赖图片。
主角选取规则：从「今天要学的词」里取第一个有核心意象的词；今天这批一个都没有时，才退回今日第一个新词。
