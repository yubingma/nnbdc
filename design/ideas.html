IDEA #004 • 2026-09-19 • 语境认知与题型创新

语境辨义：基于「释义-例句」严格绑定的情境答题与语音识义（Contextual Sense Match）

概念成型 / 机制设计
#语境辨义 #释义例句严格绑定 #熟词生义突破 #一词多义 #语音说义 #高阶题型
“词库底层架构中，每个 MeaningItem 都精确绑定了专属的 Sentence，记录着该词在此例句中的确切含义。基于这笔高精度纯净资产，彻底打破脱离语境孤立背中文标签的弊端，推出‘给例句辨词义 / 读句说词义’的特色题型与竞技玩法。”
痛点根治：攻克“熟词生义”与“长考不灵”
语境孤岛困境：传统背单词最致命的痛点是把单词抽象成一组互不相干的中文标签（如 compromise = 妥协 / 危害；plant = 植物 / 工厂；address = 地址 / 演说 / 着手处理）。用户孤立默背能选对，一旦放到考研、四六级或高考的长难句里，大脑无法在上下文中快速激活准确释义。而 NBDC 既有词库天然具备「具体释义 ↔ 专属例句」的 100% 严谨绑定，是开发情境答题的独家资产底座。
核心体验维度与玩法矩阵
① 语境辨义题（情境选择模式）

呈现地道例句，目标词高亮（如 The policy may compromise security.），让用户辨识在句中是“妥协”还是“危及”，直击考研/四六级命题核心。

② 语音说义挑战（口语流态交互）

“读句说义”：屏幕显示句子，用户直接口述目标词在句中的含义，结合已有的说英文/ASR技术快速判定，动口即过，心流极度丝滑。

③ 一词多义对照展台（详情页全景）

在单词详情页中，将多重释义按“义项 ➔ 专属例句”对联卡片一屏并列展开，与核心意象（Cognitive Schema）形成语义分支的立体呼应。

④ Russia 对战高阶题型（竞技进阶）

在俄罗斯方块对战的高分/进阶大厅中，掉落带短语境的例句辨义方块，比拼瞬时语境提取速度，大幅拉开高手差距。

技术实现基线（零新增外部实体 · 纯天然资产复用）

1. 底层数据自洽：直接复用 JPA 实体 MeaningItem.sentences 与本地 Drift MeaningItems / Sentences 既有关联，无需重新调用大模型打标签或二次标注，数据准确度 100%。
2. 客户端毫秒级离线出题：由于释义项与例句已完整下载到本地 SQLite，客户端可在本地毫秒级组装题目（例句题干 + 目标义项作为正确项 + 该词其他义项或同词性义项作为混淆项），离线无网状态下体验丝滑无阻。

IDEA #003 • 2026-09-18 • UGC生态与智能推荐

UGC 冷启动破局：AI 策展评分与动态新星展位（AI Curator & Star Slot）

概念成型 / 机制设计
#UGC生态 #AI质量评分 #打破马太效应 #冷启动激励 #动态探索与利用
“现有 UGC（助记/图片/例句）纯靠点赞数排名，导致老内容垄断顶部，优质新内容永远无曝光无点赞而沉底。引入 AI 作为专业策展人对未获充分曝光的 UGC 进行多维度评分，并在 UI 上开设专属‘新星/甄选’展位直接触达用户，经用户真实投票验证后完成冷启动转正或淘汰。”
痛点根治：终结“马太效应死锁”
冷启动死锁闭环：早期上传的内容哪怕粗糙，因占坑早积累了大量点赞而长年居顶；新上传的极佳助记/配图因点赞为 0 排在折叠深处，用户做题求快根本不会翻看，导致“无曝光 ➔ 无点赞 ➔ 永沉底 ➔ 创作者受挫流失”。AI 评分并非替代用户投票，而是作为「精准探照灯与起跑加速器」，把真正的好内容从底层打捞到聚光灯下。
核心运转逻辑与闭环设计
① 复合质量评分（AI 策展人）

在内容提交/审核时，AI 评估记忆通感、趣味生动度、释义贴合度与排版排毒，给出 0~10 分质量基准。

② 极简展位呈现（不增多余实体）

不搞冗杂榜单切换，在做题主视图或弹窗置顶区保留轻量“🌱 AI 甄选 / 新星”标识，自然融入用户视线。

③ 探索与利用（Epsilon-Greedy）

高赞经典内容占 70%~80% 稳妥展示，20%~30% 流量动态轮换给 AI 评分高的冷启动新内容接受市场检验。

④ 动态毕业与汰换机制

获得足够真实好评（如净赞 ≥ 5）即“毕业”晋升为主榜；若遭用户踩（foot ≥ 2）则快速降权退出专属位。

六大核心细节难点与自洽解法
① 曝光判定缺失（冷启动池边界）

系统无展现（impression）埋点。解法：以“创建时间 ≤ 30天 且 互动总数(hand+foot) ≤ 3”作为判定准则，超 3 次即代表已被检验自动出池。

② AI 评分时机与成本控制

复用服务端 WordImageBo.asyncReviewImage 既有异步队列，在单次请求内同步完成“合规审核 + 质量打分 + 评语”，边际成本为 0。

③ UI 呈现与极简心流

绝不在做题区并列多个臃肿榜单。主卡片保持单项展示并附极简微胶囊 🌱 AI 甄选 8.8；二级弹窗顶部保留「🌟 潜力新星」专栏。

④ 流量探索与利用（Epsilon-Greedy）

80% 稳妥展示全库净赞最高经典内容，20% 动态探索抽样 AI 高分（≥7.5）新星，防范单一依赖造成的 AI 审美幻觉与疲劳。

⑤ 动态毕业与快速淘汰闭环

新星在专属位累积获得净赞 ≥ 5 时“毕业”转正进入主榜；一旦收到 ≥ 2 个踩（foot）立即降权移出新星池，严密防刷止损。

⑥ 端云同步与离线背词兼容

本地 Drift 扩展 ai_score 与 ai_reason，通过 sys_db_sync 增量下发；客户端本地毫秒级执行 8:2 决策，离线背词体验完全自洽。

分阶段推进规划

Phase 1: 策展打分链路（服务端异步审核合并质检打分 Prompt） ➔ Phase 2: 数据表与端云同步（Drift 表扩展与增量日志兼容） ➔ Phase 3: 客户端极简微标与 8:2 混排（做题区心流呈现） ➔ Phase 4: 闭环毕业与汰换验证（新星破零留存与不良内容下架校验）。

IDEA #002 • 2026-09-17 • 对战玩法与认知博弈

对战进攻道具：形近障眼法（镜像迷雾 · Confusable Fog）

概念成型 / 机制设计
#对战道具 #形近词混淆 #认知博弈 #俄罗斯方块 #心流对抗
“给对手施加一种特殊的干扰道具：在接下来几道题中，对手答题界面的所有混淆选项，均定向替换为该单词的‘形近词’释义，使常识排除法彻底失效，大幅拉满答题难度与心智压力。”
设计痛点与认知突破
打破常规排除法：现有背单词对战中，错误选项多为词库随机抽取（如 apple 混入 destination、elephant），语义跨度大，玩家极易凭生活常识或一眼排除快速秒选。而背单词最真实的痛点是「形似意异」（如 adapt / adopt / adept、access / assess、altitude / attitude）。施加本道具后，选项全部变为形近词释义，视觉与认知双重迷惑，逼迫对手精确调动记忆，犹豫即失误。
核心机制与对战维度
① 道具定位（Debuff 进攻型）

连对 5 题随机奖励或通过特定对决策略获取。点击释放后定向对敌方施加「形近迷雾」状态。

② 影响范围（克制且致命）

持续影响对手接下来的 2~3 道下落题目，既能有效打乱对方的方块堆叠节奏，又不会造成不可逆的挫败感。

③ 混淆词库提取（高质干扰）

题干为 adopt（采纳）时，选项出现 adapt（适应）与 adept（熟练），仅凭模糊字形记忆的玩家极易误选翻车。

④ 平滑降级（无缝兜底）

若当前生僻词库中编辑距离 ≤ 2 的形近词不足 2 个，自动补齐同词根词或高频词，保证出题 100% 自洽。

技术实现与资产复用

项目已沉淀高效的 Levenshtein 编辑距离算法与形近词聚合方案（design/confusable_words_*）。在服务端 GetNextWordProcessor 生成干扰项时，检测玩家是否带有该 Debuff；若带有，则优先从词库形近词索引树中捞取干扰词释义。

IDEA #001 • 2026-09-15 • 激励与交互美学

单词泡泡天空（记忆苍穹 · Memory Aurora）

概念成型 / 减法沉淀
#成就可视化 #直连反馈 #奥卡姆剃刀 #流体粒子 #极简沉浸
“如果每掌握一个单词，就奖励一颗专属泡泡升入天空。天空可拉近查看具体单词，也可远观浩瀚苍穹，让学习积累成为看得见的浪漫资产。”
减法哲学：为何坚决舍弃“小宠物+喂糖”？
奥卡姆剃刀原则：原本构想中的“宠物嚼糖吐泡”增加了两道操作阻塞与沉重动画，容易沦为低幼小游戏并打断快速背词心流。剥离宠物后，实现「掌握单词 ➔ 单词直接化作微光气泡升空」，路径最简、反馈直连、品味高级。
核心体验维度
① 产生瞬间（微动不打断）

背词正确时，单词卡轻微呼吸化作半透明气泡向上飘散（300ms），伴随细腻触觉震动，无缝切入下一题。

② 远观态（上帝视角 · 词汇银河）

双指捏合拉远，泡泡文字渐隐为成千上万点温润流光星云，宏观感知自己亲手点亮的庞大知识宇宙。

③ 近看态（微观漫游 · 纯净交互）

手势拖拽平移漫游，轻点气泡弹性呼吸播放发音，长按展开词义例句，兼具生词本与探索展厅属性。

④ 遗忘曲线融合（生命周期）

刚掌握时泡泡清透饱满；久未复习的泡泡边缘变薄、光泽暗淡，轻戳即可触发“挽救复习”。

技术实现基线

基于 Canvas / Flutter CustomPainter 构建 2D 微重力流体粒子场。海量单词场景下采用视差分级（LOD）与视锥剔除：屏幕内精细渲染 30~50 个主焦点泡泡，远景仅渲染极低消耗的光斑粒子。

非常规黑客增长与零成本推广方案（Zero-CPC Growth Hacking）

实战策略 / 0成本冷启动
#营销推广 #黑客增长 #CPC卡死0.5元 #大厂差评截流 #FSRS算法种草 #反向打卡摆烂 #备考群资源置换 #极客媒体自荐 #双端已过审
“拒绝大厂高额买量内卷。依托‘真迹手写默写 + 语音答题 + FSRS算法 + 形式容错不搞心态’的硬核纯产出护城河，借苹果 App Store 与华为市场双端过审的信任背书，用‘大厂差评截流、算法逆向种草、反向打卡摆烂、备考群资料置换、周刊自荐白嫖’五大非常规奇招，把获客成本卡在 0.5 元以内甚至 0 成本破局冷启动。”
核心逻辑：为什么独立开发必须打“非对称战”？
红海突围的非对称打击：传统买量市场的单次点击（CPC）动辄数元甚至十几元，独立开发者盲目烧钱必死无疑。而红海大厂（百词斩、墨墨、扇贝、不背单词）长期推崇的“ABCD选择题连连看”、“死板拼写判定（手滑差一字母即判错）”、“焦虑式强迫打卡”早已在备考群体中积攒了海量怨气。这些痛点正是我们「最精准的靶心与最廉价的流量入口」。
五大非常规零成本推广奇招（实操手册）
① 竞品差评截流法（大厂用户精准收割）

场景：各大应用商店（App Store / 华为市场）及小红书/知乎大厂吐槽贴，定向抓取 1星/2星差评。

靶向：专挑抱怨“选择题自嗨考场现原形”、“拼写判定死板极易搞崩心态”、“强迫打卡制造焦虑”的精准用户。

💬 爆破话术：“狠狠共鸣了！我之前也是被大厂的选择题和机械抄写搞得考试差点凉。后来干脆自己独立开发了一款 App 叫「泡泡单词」，专门改掉这些痛点：取消 ABCD，用键盘/语音实现见义产出；形式容错、意思把关，手滑错一个字母不搞心态；配合 FSRS 算法。目前苹果和华为双端都过审了，纯净无广，嫌大厂臃肿的可以去试试。”
