# 易混淆单词簇式排序：锚点成簇、组内同长度、不接龙（Plan）

> 状态：待架构审查 → 待用户审批
> 目标：修改"易混淆单词"的**排序呈现**——由"全局贪心最近邻链式排序"改为
> **簇式排序**：每个学习过的锚点（≥3 字母）为簇头，其一字之差相近词（与锚点长度相同）
> 紧跟其后成簇；组间不接龙。准入规则（无连锁、距离 ≤1、长度相同、len≥3）保持不变。
> 纯前端本地修改，集中在 confusable_sort.dart 与测试。

## 1. 背景与需求变更

现状（锚点语义版 + 规则收紧版，Task 1 已实现）：词表 = 锚点 A（学习范围内 ∩（学习记录 ∪
已掌握））∪ 与锚点**一字之差**（同长度、距离 ≤1、len≥3、无连锁）的相近词 C，按
`confusableSort`（贪心最近邻）排序。

**用户反馈**：实际词表出现 `drum → drug → drag → rag → rage → age` 这样的长链——每个词与
相邻词都一字之差，视觉"一个连一个"，不理想。

**用户期望（已确认）**：
- 以学过的词为锚，**不希望一个连一个**；
- 排序改为**分组呈现**：每个学过的词带它的"一字之差兄弟"组成一组，组与组之间不接龙；
- **每一组的单词字母数必须相同**（与准入规则"相近词与锚点长度相同"天然一致：组内 = 锚点 +
  其同长度相近词，故组内字母数必然相同）。

示例（锚点 = {drug, age, drag}，均学习过；drum 与 drug 一字之差、rag 与 drag 一字之差、
rage 与 age 一字之差——age/rage 长度 3/4 不同会被准入排除，此处仅作示意）：

```
现在（贪心链）：drum, drug, drag, rag, rage, age        ← 一个连一个
改后（簇式）  ：drug, drum | drag, rag | age, rage      ← 组内同长度、组间不接龙
```

## 2. 设计决策

### 2.1 准入规则不变（已有实现，Task 1）

- 锚点 A = 学习范围 ∩（learning_words ∪ 已掌握），len ≥ 3；
- 相近词 C = 学习范围内、与某锚点**同长度**且编辑距离 ≤ 1（一字之差）的非锚点词，len ≥ 3，
  **无连锁**（只与锚点直接匹配）；
- 缓存签名（dictIds + B + A）、计数共用缓存等全部不变。

### 2.2 簇式排序（替代贪心 confusableSort）

新纯函数 `confusableClusterSort`（confusable_sort.dart）：

```
输入：anchors（锚点集）、selected（词表集合 = 锚点 ∪ 相近词，已准入过滤）
1. 锚点按 (spell, id) 字典序排序 → 簇头序列；
2. 归属：每个相近词 c（非锚点）归属到"与 c 一字之差（同长度、距离 ≤1）的锚点中
   (spell, id) 字典序最小者"——c 只出现一次；用长度分桶剪枝（只查 c 同长度锚点桶）；
3. 簇 = [锚点, ...其归属相近词按 (spell, id) 排序]；簇间按锚点 (spell, id) 顺序；
4. 输出 = 各簇依次展开的 id 列表。
```

- **组内字母数相同**：由准入保证（相近词与锚点同长度），簇内全部词长度一致，无需额外逻辑；
- **组间不接龙**：相近词只出现在其归属锚点簇内，不会串联到其他簇（每个相近词唯一归属）；
- **锚点互不为邻居**：锚点只作簇头出现一次，即使两个锚点互为相近词（都学过 drug/drag），
  各自成簇、互不并入；
- **无相近词的锚点**：孤立簇（仅锚点本身），仍按字典序排入序列；
- **无锚点**：词表为空（WordBo 短路逻辑不变，簇式函数对空锚点返回空）。

### 2.3 isolate 入口改造与贪心删除

- `confusableSortInIsolate`：过滤（selectConfusableNear）后调用 `confusableClusterSort`
  替代 `confusableSort`；空锚点退化路径保持"过滤 len<3 后直接簇式排序"（结果为空，语义一致）；
- **删除 `confusableSort`（贪心）及其相关测试**：簇式替代后它不再有任何调用方（易混淆是
  唯一使用者），按 AGENTS.md"清理由我的改动产生的孤儿"移除；`_delta`/`_isBetter`/`_take`
  等仅贪心使用的辅助一并清理；`_nearAnyAnchor`/`selectConfusableNear` 保留（准入用）。

### 2.4 WordBo / UI 零改动

- `getConfusableWordIds` 等调用方只依赖 isolate 入口返回值（id 顺序），无需改动；
- UI、入口计数、签名、只读语义全部不变；仅排序顺序变化。

### B. 测试

- `app/test/confusable_sort_test.dart`：
  - **删除**贪心排序相关用例（聚簇/平局/剪枝回退/随机对照等）；
  - 新增 `confusableClusterSort` 用例：
    - 锚点簇头与相近词归属（唯一锚点场景：drug 簇 = [drug, drum]）；

    - 朴素归属对照（与"归属字典序最小锚点"的朴素实现严格一致，随机/构造词集）。
  - isolate 入口：簇式输出与直接调用一致；空锚点退化一致。
- `app/test/confusable_words_bo_test.dart` / `confusable_words_provider_test.dart`：
  - 词表**集合**断言不变（准入未动）；**顺序**断言如有则改为簇式期望顺序；
  - 用用户示例词集构造一个"锚点= {drug, age, drag}"的集成用例，断言输出为

## 6. 风险与注意事项

- **顺序变化是唯一用户可见差异**：词表集合（哪些词出现）不变，仅排列方式从链式变为簇式；
  缓存/签名/计数不受影响。
- **归属规则**：相近词同时与多个锚点一字之差时归属字典序最小锚点——确定性、可测；
  若用户希望"归属最近的锚点"或"允许重复出现"可再调（记录为可调项）。
- **删除贪心排序**：`confusableSort` 及其 11 个测试删除；如后续有其他场景需要贪心链式排序，
  可从 git 历史恢复（记录说明）。
- **age/rage 示例澄清**：age(3) 与 rage(4) 长度不同，按"长度相同"准入本就不会匹配；
  用户示例词表中若出现此类跨长度词对，是旧规则数据或该词与别的同长度锚点匹配，属预期。
