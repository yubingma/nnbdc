💡 Flutter 端落地实现方案（极低成本）：

在 Flutter 中无需引入复杂的第三方图形引擎，只需使用普通的 Container + LinearGradient + RepaintBoundary，点击分享按钮时调用 boundary.toImage() 即可生成无损超清海报。 

// 1. 用 RepaintBoundary 包裹海报组件
final GlobalKey _posterKey = GlobalKey();

RepaintBoundary(
  key: _posterKey,
  child: DakaPosterWidget(
    continuousDays: user.continuousDakaDayCount,
    todayWordCount: 30,
    totalWords: user.masteredWordsCount,
    theme: PosterTheme.aurora,
  ),
);

// 2. 点击分享时将 Widget 转换为图片并调用原生分享
Future sharePoster() async {
  RenderRepaintBoundary boundary = _posterKey.currentContext!.findRenderObject() as RenderRepaintBoundary;
  ui.Image image = await boundary.toImage(pixelRatio: 3.0); // 3x超清
  ByteData? byteData = await image.toByteData(format: ui.ImageByteFormat.png);
  // 使用 share_plus 分享图片到微信 / 朋友圈 / 保存相册
}
