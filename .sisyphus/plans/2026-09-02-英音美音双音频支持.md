# 英音/美音双音频支持 Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 为单词发音增加英音/美音双音频支持:后端为每个单词生成 `_uk.mp3`(英音)与 `_us.mp3`(美音)双轨音频,前端新增全局"发音口音"偏好(英音/美音),播放与音标展示随偏好走,并在管理后台提供批量补齐入口。

**Architecture:** 后端将有道发音下载逻辑收敛为公共方法 `downloadWordSound`(支持口音后缀),批量补齐沿用 `AdminCigenOptimizeController` 的内存态任务模式(start/status/stop 三接口)。前端通过 `Prefs` 存 `pronunciation_accent` 偏好,`getWordSoundUrl` 按偏好拼 `_uk`/`_us` 后缀;播放层 `playSoundByUrl` 在加载失败时自动回退另一口音,再失败才走系统 TTS 兜底。音标展示 `mergedPronounce`/`getWordDefaultPronounce` 按偏好选对应音标。

**Tech Stack:** Spring Boot (Java) / Flutter (Dart) / 有道词典发音接口 (`dict.youdao.com/dictvoice`) / 阿里云 CosyVoice TTS 兜底 / SharedPreferences

**实测已验证的事实:**
- 有道 `type=1`(美音)与 `type=2`(英音)对常见词均返回 200,音轨 MD5 不同(真实双轨音频存在)
- 前端 `playSoundByUrl` 已有"URL 加载失败 → 系统 TTS 兜底"的自愈链路,可作为口音回退挂载点(零预探测、零额外网络往返)
- word 表已有 `america_pronounce`/`british_pronounce` 双字段,音标数据源已具备

**Step 2: 在 `WordBo` 增加公共方法 `downloadWordSound(String spell, String accentSuffix)`**

核心:通过有道下载单个口音的 mp3 到 `/{soundPath}/{firstChar}/{spell}{accentSuffix}.mp3`,失败则 CosyVoice TTS 兜底,返回成功/失败。

从现有 `regeneratePronunciation`(311-379 行)抽取可复用部分,签名与逻辑:
```java
/**
 * 下载单词指定口音的发音 mp3 到 sound 目录。
 * 优先有道 dictvoice,失败回退 CosyVoice TTS(按口音附加发音指令)。
 *
 * @param spell        单词拼写
 * @param accentSuffix "_uk"(英音) / "_us"(美音) / null(旧版无后缀)
 * @return 目标文件路径;失败返回 null
 */
public String downloadWordSound(String spell, String accentSuffix) throws Exception {
    String pureSpell = Utils.uniformSpellForFilename(spell);
    if (pureSpell.isEmpty()) return null;
    String fileName = Utils.getWordSoundFileName(spell, accentSuffix);

    String firstChar = pureSpell.substring(0, 1);
    File dir = new File(sysParamUtil.getSoundPath() + "/" + firstChar);
    if (!dir.exists()) dir.mkdirs();
    File soundFile = new File(dir, fileName + ".mp3");
    if (soundFile.exists() && soundFile.length() > 0) {
        // 已存在有效文件,跳过下载(幂等)
        return soundFile.getAbsolutePath();
    }

    boolean isUk = "_uk".equals(accentSuffix);
    String[] urlStrs;
    if (isUk) {
        urlStrs = new String[]{
            "http://dict.youdao.com/dictvoice?type=2&audio=" + URLEncoder.encode(pureSpell, "UTF-8"),
            "http://dict.youdao.com/dictvoice?le=eng&audio=" + URLEncoder.encode(pureSpell, "UTF-8")
        };
    } else {
        urlStrs = new String[]{
            "http://dict.youdao.com/dictvoice?type=1&audio=" + URLEncoder.encode(pureSpell, "UTF-8"),
            "http://dict.youdao.com/dictvoice?le=eng&audio=" + URLEncoder.encode(pureSpell, "UTF-8")
        };
    }

    // 1) 尝试有道
    for (String urlStr : urlStrs) {
        HttpURLConnection conn = (HttpURLConnection) new URL(urlStr).openConnection();
        conn.setRequestMethod("GET");
        conn.setConnectTimeout(3000);
        conn.setReadTimeout(5000);
        if (conn.getResponseCode() == 200) {
            try (InputStream is = conn.getInputStream();
                 FileOutputStream fos = new FileOutputStream(soundFile)) {
                byte[] buffer = new byte[4096];
                int bytesRead;
                while ((bytesRead = is.read(buffer)) != -1) fos.write(buffer, 0, bytesRead);
                fos.flush();
            }
            if (soundFile.length() > 0) {
                log.info("有道发音下载成功: {} (suffix={})", soundFile.getAbsolutePath(), accentSuffix);
                return soundFile.getAbsolutePath();
            }
        }
    }

    // 2) 回退 CosyVoice TTS(按口音附加指令)
    String ttsInstruction = isUk
        ? "Speak in a clear British English accent."
        : "Speak in a clear American English accent.";
    try {
        AiBo.TtsResult ttsResult = aiBo.generateSpeech(pureSpell, null, ttsInstruction);
        if (ttsResult.audioData != null && ttsResult.audioData.length > 0) {
            try (FileOutputStream fos = new FileOutputStream(soundFile)) {
                fos.write(ttsResult.audioData);
                fos.flush();
            }
            log.info("TTS 兜底发音成功: {} (suffix={})", soundFile.getAbsolutePath(), accentSuffix);
            return soundFile.getAbsolutePath();
        }
    } catch (Exception e) {
        log.warn("TTS 兜底发音失败: {} suffix={}", spell, accentSuffix, e);
    }
    return null;
}
```

**Step 1: 创建控制器(仿 `AdminCigenOptimizeController`)**

三段式接口 + 内存态任务:

```java
package beidanci.service.controller;

import org.slf4j.Logger;
import org.slf4j.LoggerFactory;
import org.springframework.beans.factory.annotation.Autowired;
import org.springframework.web.bind.annotation.GetMapping;
import org.springframework.web.bind.annotation.PostMapping;
import org.springframework.web.bind.annotation.RequestParam;
import org.springframework.web.bind.annotation.RestController;

import beidanci.api.Result;
import beidanci.service.bo.UserBo;
import beidanci.service.bo.WordBo;
import beidanci.service.po.User;
import beidanci.service.po.Word;

import java.util.ArrayList;
import java.util.HashMap;
import java.util.List;
import java.util.Map;

@RestController
public class AdminPronunciationFixController {
    private static final Logger logger = LoggerFactory.getLogger(AdminPronunciationFixController.class);

    @Autowired
    private WordBo wordBo;

    @Autowired
    private UserBo userBo;

    private static final PronunciationFixTask currentTask = new PronunciationFixTask();

    /**
     * 启动批量补齐任务。fixUk/fixUs 控制要补哪些口音(至少一个为 true)。
     */
    @PostMapping("/admin/pronunciation/startFix.do")
    public Result<String> startFix(@RequestParam("userId") String userId,
                                   @RequestParam(value = "fixUk", defaultValue = "true") boolean fixUk,
                                   @RequestParam(value = "fixUs", defaultValue = "true") boolean fixUs) {
        synchronized (currentTask) {
            if (currentTask.isRunning) {
                return Result.fail("有一个发音补齐任务正在运行中，请稍后再试");
            }
            User user = userBo.findById(userId);
            if (user == null || !user.getIsAdmin()) return Result.fail("无权限");

            currentTask.reset();
            currentTask.isRunning = true;
            currentTask.fixUk = fixUk;
            currentTask.fixUs = fixUs;

            new Thread(() -> {
                try {
                    List<Word> allWords = wordBo.getAllWords();
                    currentTask.totalIndices = allWords.size();
                    currentTask.statusMsg = "正在逐词补齐发音...";
                    int ukOk = 0, usOk = 0, ukFail = 0, usFail = 0;

                    for (int i = 0; i < allWords.size(); i++) {
                        if (!currentTask.isRunning) break;
                        Word w = allWords.get(i);
                        currentTask.currentIndex = i + 1;

                        try {
                            Map<String, Object> log = new HashMap<>();
                            log.put("spell", w.getSpell());
                            if (currentTask.fixUk) {
                                String ukPath = wordBo.downloadWordSound(w.getSpell(), "_uk");
                                if (ukPath != null) { ukOk++; log.put("uk", "OK"); }
                                else { ukFail++; log.put("uk", "FAIL"); }
                            }
                            if (currentTask.fixUs) {
                                String usPath = wordBo.downloadWordSound(w.getSpell(), "_us");
                                if (usPath != null) { usOk++; log.put("us", "OK"); }
                                else { usFail++; log.put("us", "FAIL"); }
                            }
                            synchronized (currentTask) {
                                currentTask.ukOk = ukOk; currentTask.usOk = usOk;
                                currentTask.ukFail = ukFail; currentTask.usFail = usFail;
                                // 仅记录失败的(成功数量太大,避免日志爆炸)
                                if (log.containsKey("uk") && "FAIL".equals(log.get("uk"))
                                        || log.containsKey("us") && "FAIL".equals(log.get("us"))) {
                                    currentTask.failedLogs.add(log);
                                }
                            }
                        } catch (Exception e) {
                            logger.error("发音补齐异常: word=" + w.getSpell(), e);
                            Map<String, Object> log = new HashMap<>();
                            log.put("spell", w.getSpell());
                            log.put("error", e.getMessage());
                            synchronized (currentTask) { currentTask.failedLogs.add(log); }
                        }
                    }
                    currentTask.statusMsg = currentTask.isRunning ? "发音补齐任务完成" : "任务已中止";
                } catch (Exception e) {
                    logger.error("发音补齐任务异常", e);
                    currentTask.statusMsg = "任务异常退出: " + e.getMessage();
                } finally {
                    currentTask.isRunning = false;
                }
            }).start();

            return Result.success("发音补齐任务已启动");
        }
    }

    @GetMapping("/admin/pronunciation/fixStatus.do")
    public Result<PronunciationFixTask> getFixStatus() {
        return Result.success(currentTask);
    }

    @PostMapping("/admin/pronunciation/stopFix.do")
    public Result<String> stopFix(@RequestParam("userId") String userId) {
        User user = userBo.findById(userId);
        if (user == null || !user.getIsAdmin()) return Result.fail("无权限");
        currentTask.isRunning = false;
        currentTask.statusMsg = "已手动中止";
        return Result.success("已请求停止任务");
    }

    public static class PronunciationFixTask {
        public boolean isRunning = false;
        public boolean fixUk = true;
        public boolean fixUs = true;
        public int totalIndices = 0;
        public int currentIndex = 0;
        public int ukOk = 0;
        public int usOk = 0;
        public int ukFail = 0;
        public int usFail = 0;
        public String statusMsg = "等待中";
        public List<Map<String, Object>> failedLogs = new ArrayList<>();

        public void reset() {
            isRunning = false;
            fixUk = true;
            fixUs = true;
            totalIndices = 0;
            currentIndex = 0;
            ukOk = 0; usOk = 0; ukFail = 0; usFail = 0;
            statusMsg = "等待中";
            failedLogs.clear();
        }
    }
}
```

## 风险与备注

1. **有道 type=2 是否为真英音**:实测确认返回不同 MD5 音轨,但音色需试听抽查。若 type=2 实际为美音,需换源(如有道 `type=0`/其他)。**实施第一步(手动验证)先抽查试听确认**。
2. **CosyVoice 英音指令效果**:`generateSpeech` 的 `voiceInstruction` 是文本指令,能否真正产出英音取决于模型支持。若效果差,批量补齐时英音失败率高,需在管理页失败日志中观察。
3. **批量任务内存态**:与 cigen 一致,重启丢失;单机部署够用,不引入 Redis。
4. **`getWordSoundUrl` 行为变化**:所有调用点 URL 从 `{spell}.mp3` 变为 `{spell}_us.mp3`(默认美音)。存量 `_us` 未生成时回退机制兜底,不影响现有用户。
