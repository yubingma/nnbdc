从「认得」到「说得出」

能不能说出口、多义词怎么挂住、背不动时怎么办、坚持有没有回响——这四件事，泡泡单词都做了。

开口说

不选 ABCD，把答案说出来

看中文说英文、看英文说意思——答案得靠嘴巴给出来，而不是在四个选项里认脸。 App 会听懂你说了什么：先用随包携带的发音词典（CMU，12.6 万词条）逐音比对， 本地拿不准的时候再请大模型裁决，同义词和口音都认。

选择题能靠排除法蒙对，说出来的只有一个答案。

实时对战

背不动的时候，去打一局

和真实对手在同一批词上实时对战，答题爆破泡泡，谁先答对谁得分。考研核心、英语四六级、托福各有专属场次， 也可以自己开房，把房间号发给朋友，用同一本词书比一场。

赢的是排名，答错的词会回到你的复习队列——玩和学，算的是同一笔账。

坚持看得见

把坚持做成墙上的勋章

连击 3 天种下「萌芽初醒」，21 天点亮「习惯微光」，100 天铸成「百日筑基」； 掌握 100 词是「破冰启航」，1000 词是「千词过海」，满分测验还会记下你到底做到了多少次。

每枚勋章都带着清晰的进度——比如 780 / 1000 词，离下一枚还有多远，一眼就知道。

一词多义

一个词的意思，其实是一张图

spring 是春天、是泉水、是弹簧、也是跳跃——「从压缩状态猛然弹出」这一个动作，在不同场景里长成了四张面孔。 泡泡单词为这样的词画一张核心意象图，把散落的释义串成一条引申脉络。

多义词不必硬背四行中文，记住那个画面就够了。

还有这些每天都在用的能力

从复习排期到发音纠音，装好就有。

FSRS-5 记忆排期

每次作答后按 FSRS-5 模型重算记忆稳定度，推算出这个词该在第几天与你重逢——该复习的当天出现，不该复习的绝不占用你的时间。

多种学习模式

遮挡中文、遮挡英文、拼字母、手写拼写、说中文、说英文、翻译例句，换着练，避免只认得位置。

形近词并排对比

以你学过的词为锚点，把拼写只差一两个字母的「邻居」找出来并排摆放，affect 和 effect 不再看走眼。

同根词一族

按词根把同源词聚成一族，act / action / active / react 一起记，一个词根认一串词。

随身听

全屏沉浸式听单词，配环境白噪音，锁屏也能听；听到哪，书签自动记到哪。

AI 情境短文

把一批词串成一篇小短文，点文中任意单词直接查词，中英双语音频对照。

词书与自建词书

四六级、考研、雅思、托福等分类词书，细到人教版、外研版这样的教材版本；也能从 Excel 导入自己的词表。

打卡海报与热力图

完成当天计划即打卡成功，一键生成海报分享到微信好友或朋友圈；30 天色块看清自己有没有偷懒。
